# Скажи слово

Мобильный тренажёр английского для записи слов, проверки перевода и повторной озвучки

**Ссылка для телефона и учеников:** [Открыть тренажёр](https://mva2024.github.io/say-a-word-trainer/?v=929b65f)

## Как пользоваться

1. Открой ссылку на телефоне или компьютере
2. Выбери «Английский → Русский» или «Русский → Английский»
3. Нажми «Старт», разреши доступ к микрофону и произнеси слово
4. Проверь, что браузер услышал, вспомни перевод и нажми «Перевод»
5. Нажми на перевод в истории, чтобы услышать его ещё раз

История хранит последние пять переводов в браузере. На другом телефоне, компьютере или в другом профиле будет своя история

## Установка на телефон

Кнопка «Установить приложение» появляется, когда браузер предлагает установку. В Safari на iPhone можно использовать «Поделиться» → «На экран Домой». Для распознавания речи в Safari нужна включённая Siri

Тренажёр опубликован по HTTPS на GitHub Pages и доступен при выключенном компьютере владельца. Для обращения к MyMemory нужен интернет

## Код и публикация

- `index.html` содержит интерфейс, запись и озвучку через Web Speech API, запросы к MyMemory и историю в `localStorage`
- `manifest.webmanifest`, `sw.js`, `icon-192.png` и `icon-512.png` обеспечивают установку в поддерживаемых браузерах. Service worker сохраняет страницу для открытия без сети
- [Репозиторий GitHub](https://github.com/MVA2024/say-a-word-trainer) и [основной адрес GitHub Pages](https://mva2024.github.io/say-a-word-trainer/)
- Проверенный выпуск `929b65f` включает компактную шапку без волны, кнопку установки и подсказку «Нажмите „Старт“ и скажите слово» в режиме английский → русский

## Лимиты и проверки

Один запрос ограничен 500 байтами текста в UTF-8. MyMemory указывает бесплатную анонимную квоту 5 000 символов в сутки. При общей сети ученики могут расходовать одну квоту. В тренажёре нет счётчика переведённых слов или ограничения числа одновременных пользователей. [Документация MyMemory](https://mymemory.translated.net/doc/spec.php), [квоты MyMemory](https://mymemory.translated.net/doc/usagelimits.php)

Проверены реальный перевод `apple → яблоко` и `книга → book`, раскладка на ширинах 360 и 768 пикселей и доступ Chrome к микрофону Realtek на компьютере. Выпуск GitHub Pages и ссылка для телефона вернули HTTP 200. Логику кнопки установки проверили с имитацией браузерных событий. Установку PWA на физическом телефоне пока не проверяли
